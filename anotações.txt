============================================================
API - PEÇA POR PEÇA
===================

API responsável pelo funcionamento do aplicativo
Peça por Peça, uma plataforma de troca de peças eletrônicas.

## TECNOLOGIAS

* PHP 8.3+
* Laravel 13
* MySQL
* Laravel Sanctum
* React Native / Expo
* Axios
* Git

============================================================

1. CONFIGURAÇÃO INICIAL
   ============================================================

Abra o terminal dentro da pasta do projeto.

Instale as dependências da API:

```
composer install
```

Crie o arquivo .env:

```
copy .env.example .env
```

Gere a chave do Laravel:

```
php artisan key:generate
```

============================================================
2. CONFIGURAÇÃO DO BANCO
========================

Abra o arquivo:

```
.env
```

Confira as configurações:

```
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=bdd_peca_por_peca
DB_USERNAME=root
DB_PASSWORD=
```

Banco utilizado:

```
bdd_peca_por_peca
```

============================================================
3. DEPENDÊNCIAS DO APLICATIVO
=============================

Na pasta do React Native:

```
npm install
```

============================================================
4. RODAR O PROJETO
==================

API Laravel:

```
php artisan serve
```

Aplicativo React Native:

```
npm start
```

============================================================
5. ANTES DE COMEÇAR A TRABALHAR
===============================

Sempre atualize o projeto:

```
git pull
```

Depois faça suas alterações normalmente.

============================================================
6. ENVIAR ALTERAÇÕES PARA O GITHUB
==================================

Quando terminar suas alterações:

1. Verificar as alterações:

   git status

2. Adicionar as alterações:

   git add .

3. Criar o commit:

   git commit -m "Descrição da alteração"

Exemplo:

```
git commit -m "Corrige edição de anúncios"
```

4. Enviar para o GitHub:

```
git push
```

============================================================
7. FLUXO DO GIT
===============

ANTES DE COMEÇAR:

```
git pull
```

FAZER AS ALTERAÇÕES

DEPOIS DE TERMINAR:

```
git status
git add .
git commit -m "Descrição da alteração"
git push
```

============================================================
8. TRABALHO EM EQUIPE
=====================

Antes de começar a trabalhar:

```
git pull
```

Faça suas alterações.

Depois envie:

```
git add .
git commit -m "Descrição da alteração"
git push
```

============================================================
9. IMPORTANTE
=============

O arquivo .env não deve ser enviado para o GitHub.

Cada computador deve possuir seu próprio arquivo .env.

============================================================
10. COMANDOS PRINCIPAIS
=======================

API:

```
composer install
php artisan key:generate
php artisan serve
```

APLICATIVO:

```

```

GIT:

```
git pull

```
